# Recherche sur la carte CLAP

Le champ de la carte cherche une commune, une rue, une adresse ou un code postal. Choisir un résultat recentre la carte et recharge les boîtes du nouveau cadrage, sans filtrer leur nom ou leur adresse. Le tableau conserve sa recherche dans les boîtes enregistrées. La liste `/api/communes` reste réservée au formulaire d’ajout : elle contient les communes CLAP, pas un index géographique de rues ou de coordonnées.

Le serveur interroge [l’index des adresses de la Géoplateforme IGN](https://cartes.gouv.fr/aide/fr/guides-utilisateur/utiliser-les-services-de-la-geoplateforme/geocodage/), alimenté par la Base Adresse Nationale. Il ne transmet ni cookie, ni en-tête de session, ni position de la carte : seulement le texte saisi et les paramètres de recherche. Les premiers résultats arrivent après 320 ms sans frappe, à partir de trois caractères. Le délai maximal côté fournisseur est de 3,5 s. Le champ rend jusqu’à six suggestions ; flèches et Entrée permettent de choisir, Échap ferme la liste.

Les accents, les variantes et les préfixes dépendent de la correspondance de l’IGN. Une rue homonyme peut nécessiter la commune ou le code postal. Un code postal complet recherche les localités dont le code renvoyé correspond exactement ; le code peut désigner plusieurs communes, ou un arrondissement. Le classement et la couverture dépendent de la BAN ; une rue non indexée ne peut pas être trouvée et un résultat n’implique pas qu’une boîte existe à proximité. Les suggestions ne remplacent pas la recherche du tableau si le fournisseur est indisponible.
